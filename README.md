# DeepSeek 小鲸鱼桌宠（独立版）

DeepSeek Balance Whale Widget 的**独立桌面宠物版** —— 不再依赖浏览器 / DSH Web 界面。

桌面右下角的透明置顶小鲸鱼：实时显示 DeepSeek API 余额 + 今日已用 + 每轮对话消耗，
可通过内置 **API 中转**（OpenAI 兼容）统计每一次 chat/completions 调用的真实 token 消耗。

## 与 DSH 版的区别

| | DSH 插件版（原仓库） | 本独立版 |
|---|---|---|
| 运行环境 | DSH Web 界面（浏览器） | 独立 exe / Python 进程 |
| 余额拉取 | DSH 宿主的凭据服务 | 自定义配置（首次启动填入） |
| 每轮对话消耗 | 监听 DSH 会话事件 | **内置 API 中转**：客户端把 base_url 指向 `http://127.0.0.1:11434/v1`，中转转发到 DeepSeek 并统计 usage |
| 今日已用 | 小鲸鱼记账 / 实时令牌 | 相同（记账默认 / 令牌可选） |
| 配置 | `~/.dsh/` | `%APPDATA%\WhalePet\config.json`（便携：exe 同目录 config.json） |

## 快速开始（Python 运行）

```powershell
pip install -r requirements.txt
python main.py
```

首次启动弹出设置窗口，填入 **DeepSeek API Key**（必需，用于拉余额 + 中转转发），
保存后会自动缓存到 `%APPDATA%\WhalePet\config.json`，之后不再询问。

## 打包为独立 exe

```powershell
python release.py         # 仅打包，产物 dist\WhalePet.exe
python release.py 0.3     # 打包 + 提交 + 打标签 v0.3 + 推送 + 发布 GitHub Release
python release.py 0.3 -y  # 同上，跳过发布前二次确认
```

产物：`dist\WhalePet.exe`（单文件，含资源，约 53 MB）。首次运行同样弹出配置窗口。

发布模式会自动生成 Release 说明（含 SHA256 校验值与下载说明），发布前会二次确认；
需本机已安装 [GitHub CLI](https://cli.github.com/) 并执行过 `gh auth login`。

## 使用方式

- **查看余额**：点击小鲸鱼 → 气泡显示余额 + 今日已用（5 秒自动收起）。**气泡还在时点击 = 换一条随机台词，
  并重新计时 5 秒**（连点就一直换台词，点不没；余额 / 计费 / 预警 / 启动气泡都一样，
  计费气泡被点击后也按普通气泡 5 秒收起；**最近两次出现过的那条台词不会马上重复**）。
- **自动事件也会续时**：气泡还看得见时，轮询（不管余额有没有变化）或轮计费凑过来了，
  都会把停留时间重新计时（普通/计费气泡按 5 秒、预警气泡按 8 秒），所以气泡不会“刚触发就被收走”；
  内容不会被自动事件乱改（计费泡仍是计费内容，轮询只续时）。
- **点击后 1 秒保护期**：刚点完台词时，若同时撞上轮询 / 轮计费，这些自动效果会**排队延后 1 秒**再执行
  （金额、账本等数据照常立刻更新，只是气泡内容晚 1 秒切换），先让你把点出来的那句看完；
  连点会顺延到最后一次点击之后。
- **拖拽**：按住小鲸鱼拖动，松手后自动吸附到最近的四分之一边缘（四边 + 角组合）；吸附到左缘时整体镜像（文字保持可读）。
- **按压**：按下有小 Q 弹 + 音效（小黄鸭 / 音效1，可在设置中切换、调音量）。
- **自适应轮询**：基础每 60 秒静默刷新；若既没有走中转调用、余额也和上次一样，间隔每次
  **+100%**（60s → 120s → 240s … 上限 30 分钟）；一旦有中转调用、或余额与上次不一致，
  立刻重置回 60 秒。余额变化时数字滚动 + 弹气泡。
- **账单统计**：右键菜单 / 托盘 → 「账单…」，查看今天 / 最近 7 天 / 30 天 / 90 天的
  每日消耗与**按模型**汇总（金额 / 占比 / Token / 轮次）。
- **预警**：余额低于阈值、今日已用超过阈值时自动弹气泡 + 托盘通知（阈值在设置里改）。
- **台词词典**：随机台词、峰谷文案都在独立的 `phrases.json` 里，右键 / 托盘 → 「台词词典…」
  （或设置 → 「台词词典 → 打开词典页…」）打开**词典编辑页**：左边选台词组，右边改权重 / 类型 / 样式 /
  换行 / 音效与每一条台词，支持新建 · 复制 · 删除 · 排序；点「保存」即生效（桌宠自动重载，不用重启）。
  页面里也留了「用文本编辑器打开」给习惯直接改 JSON 的人，写坏了还能一键「恢复内置默认」。
- **右键菜单 / 托盘**：设置、账单、台词词典、刷新余额、**气泡**（换一条台词 / 收起气泡 / 启用台词气泡）、
  显示隐藏小鲸鱼、退出（同一时间只允许一个实例，需多开时设环境变量 `WHALE_PET_ALLOW_MULTI=1`）。
- **界面风格**：右键菜单、托盘菜单与设置 / 账单 / 词典页统一是 Win11 风格 —— 圆角 + 半透明磨砂玻璃
  （Windows 11 上走 DWM 亚克力模糊，老系统自动降级成半透明卡片）。

## 自定义台词词典

小鲸鱼气泡里的随机台词（含峰谷文案）**不是写死在代码里的**，而是放在一个独立的 JSON 词典里：

```text
%APPDATA%\WhalePet\phrases.json     # 便携模式 = exe / 项目同目录
```

首次运行会自动生成一份与内置台词相同的默认词典（文件里的 `"_说明"` 字段写了完整格式）。
打开方式：右键小鲸鱼 / 托盘 → 「台词词典…」，或设置 → 「台词词典 → 打开词典页…」——
打开的是**词典编辑页**（不再是直接丢进文本编辑器）：左边选组、右边改属性与台词，保存即生效；
想直接改 JSON 就点页面里的「用文本编辑器打开…」，改完回到页面点「重新加载」。
编辑保存后**立即生效**（桌宠按文件指纹自动重载，不用重启），例如：

```json
{
  "groups": [
    { "weight": 45, "type": "peak",
      "texts": { "default": { "off": "空闲时段", "peak": "高峰时段" } } },
    { "weight": 7, "style": "B", "lines": ["好模型... ↓", "好女孩...↓"] },
    { "weight": 7, "style": "A", "wrap": true, "lines": [
        ["第一行大字，长句自动换行", { "text": "第二行小字", "style": "C" }],
        "或者就一句话" ] },
    { "weight": 10, "type": "gif" },
    { "weight": 1, "sfx": "ciallo", "lines": [
        [ { "text": "Ciallo～", "style": "B" }, { "text": "(∠・ω< )⌒☆", "style": "C" } ] ] }
  ]
}
```

- `groups`：每次弹台词先按 `weight`（权重，默认 1）随机挑一组，再从该组 `lines` 里随机挑一条；
  `"enabled": false` 整组停用，`weight <= 0` 或格式不对的组直接忽略。
- 一条备选台词可以写成 `"文本"`、`{ "text": "...", "style": "B" }`，
  或一个列表（= 一次显示多行的成套台词，如内置峰谷组）。
- 样式：`A` 普通台词 / `B` 大字台词 / `P` 强调大字（默认按峰谷红绿，可用 `color` 指定色值）/ `C` 小字提示。
- 组里还可以带 `"sfx": "ciallo"`：显示这组台词时播放同名音频（自带淡入淡出），查找顺序为
  `sounds/`（与 config.json 同目录，默认 `%APPDATA%\WhalePet\sounds\`）→ 内置 `assets/`；
  同一目录按 `wav → mp3 → aac → m4a → ogg → flac` 取第一个，都没有则静默。
  程序运行中**替换 / 删除音频文件即时生效**（不用重启，播完自动松开文件占用）。
  想换成自己的音频（如柚子社的 Ciallo 配音，请自行确认使用授权）直接放
  `sounds\ciallo.mp3`（或 .aac 等）即可，不用重新打包；内置的 `Ciallo～(∠・ω< )⌒☆` 组就用了它。
- 余额预警气泡会随机说「没有 token 了，要饿死了……」或「肥鱼巧施连环计，用户误失大白饭。」。
- `type: "peak"` 是内置动态组（当前时段 + 今日已用）：`texts` 的键对应设置里的「峰谷文案」，
  也可以自己加（如 `"moyu": { "off": "摸鱼谷", "peak": "摸鱼峰" }`，再把 config.json 的
  `peak_mode` 填成 `moyu`）；`type: "gif"` 是表情动图组，不带文字。
- 写坏也没关系：文件读不出来时自动退回内置默认台词（打开词典时会提示原因）；
  想恢复出厂设置，删掉文件即可重新生成。

## 让 AI 客户端走中转（统计每轮消耗）

任何 OpenAI 兼容客户端把 `base_url` 改为：

```
http://127.0.0.1:11434/v1
```

示例（OpenAI SDK）：

```python
from openai import OpenAI
client = OpenAI(api_key="<任意值>", base_url="http://127.0.0.1:11434/v1")
resp = client.chat.completions.create(model="deepseek-chat", messages=[...])
```

中转会把请求转发到 `config.json` 里的 `api_base`（默认 `https://api.deepseek.com`），
从响应 usage 按**峰谷定价**（工作日高峰 9-12/14-18 点；2026-08-23 起周末全天谷价）
换算成本，小鲸鱼随即弹出「上一轮对话消耗 ¥X.XX」。

- 流式请求（`stream=True`）也支持：边转发边收集 usage。
- **快速连轮累加**：气泡还没收起又来一轮时，**不再把显示切换成新一轮的数值**，
  而是直接累加：标题变成「连续 N 轮对话消耗」，金额与 token 显示这一段连续轮次的
  总和（数字平滑滚动到累计值）；气泡收起恢复余额内容后归零，下一轮重新从 1 起算。
- **点击计费气泡**：切成一条随机台词（重新计时 5 秒），这段「连续 N 轮」的累计随之结束，
  下一轮从 1 重新起算。
- `GET /v1/models`、`GET /healthz` 可用于联通性检查。

## 说明

- 记账模式（默认）：每天首次启动时缓存当日**资金初始值**，用「观测到的余额下降」累计今日已用；
  账本持久化，重启后拿上次观测值与当前余额作差，**程序关闭期间的消耗也能补上**。
- 每轮对话消耗走中转统计，**立刻叠加**到「今日已用」（不等 60 秒轮询）；
  轮询同步后再用 `(+0.12)` / `(-0.04)` 标出**当前轮**的偏离值 =（上次同步后新增的实测消耗 - 新增的每轮预估），
  气泡里这个括号会按正负着绿 / 红，一眼看出偏差方向；
  只反映最近一轮 / 这一批连轮，**不整天累计**（下次同步重新起算，没统计到任何一轮时不显示）。
  快速连轮时气泡按「连续 N 轮对话消耗」累计金额 / token（不再切换成单轮数值）。
- 实时·令牌模式：在设置中填入 DeepSeek 平台会话令牌（`Bearer eyJ...`）后，直接调平台用量接口精确换算。
- 长期记账：账本按天归档（含每个模型的金额 / Token / 轮次），保留 **730 天**；
  旧版账本（只存当天总额）会自动兼容读取。账本 = 与 `config.json` **同目录**的
  `ledger.json`（默认 `%APPDATA%\WhalePet\`，便携模式为 exe 同目录），源码运行与打包版
  共用同一份；启动时直接读缓存，**每次轮询都会对比文件并合并**外部改动，
  写入用原子替换，并默认单实例运行 —— 不会再现“重启 / 多开就归零”。
  旧位置（源码目录 `ledger.json`、旧版 `usage.json`）的数据首次启动会自动并入历史。
- 按模型统计：本地中转每轮写入模型明细；实时·令牌模式下以平台按模型数据为准，
  上次同步后新发生的本地消耗继续叠加（与「今日已用」同一套“基准 + 增量”口径）。
- 预警：`alert_balance`（余额低于）/ `alert_daily`（今日已用超过）两个阈值，
  0 或关闭开关即不提醒；每日预警每超过一档（如 2×、3× 阈值）会再提醒一次，重启不重复。
- 定价常量在 `pet/pricing.py`，DeepSeek 调价时可直接修改。
- 随机台词来自用户词典 `pet/phrases.py` + `phrases.json`（与 `ledger.json` 同目录）：
  默认词典与拆分前的硬编码台词逐条一致（权重 45/7/7/10/3/1），未改动时行为完全不变。
